# 使用者偏好：holo-maker（範例設定）

> 這是**一位使用者**的設定範例，換人時整份改寫。通用做法見 `SKILL.md` 與 `references/`。

## 溝通

- 用**繁體中文**；少用英文術語，必用的要解釋。
- **最討厭麻煩**：手動管理檔案、串接服務、驗證成果、反覆試錯，都希望 Claude 接手。
- 希望主對話**只協調、派 agent 做事**；擔心主對話自己動手後被技術細節帶走，回報變成一堆術語。
- 生成要等很久 → 一律在背景執行，不要卡住對話。
- 眼光很細：尾巴質感、接縫、從底部看的破洞、腰部錯位都看得出來。
- 檢查破洞時，希望只留接合區附近、其他部位隱藏。
- 不喜歡選項太多：一堆分頁會不知道要看哪個。
- 不滿意時要「一個一個檢討」，且不要給他減面或重烘貼圖的模型看。
- 很在意「實際做法跟說的一樣」：曾抓到程式偷換做法。
- 覺得任務太慢時，會問是不是一次派太多 → 任務要切小。

## 審美

### 概念圖（1/7 比例 PVC 手辦商品照風格）

- 無底座、無支架、無場景，乾淨的無縫背景。
- 全年齡向：不露事業線、不要過膝襪；不要紫色。
- 姿勢用「情境和心情」描述，不要逐一描述手腳位置；要像真的手辦姿勢，趴姿、躺姿通常不好。
- 道具要有理由才放；想不到就不放（鬧鐘、綿羊、可可被否決過）。道具上不要有文字或商標。
- 畫面不要太滿太亂；衣服皺褶不要太多。
- 連身睡衣類：從頭到腳同一套；頭髮收在衣服裡時，背後的頭髮不畫在外面。
- 漂浮感的東西（如雲朵）要真的有漂浮感。
- 否決過的主題：賽車女郎。
- 圖像模型常見毛病：秤之類的道具畫太大、酒桶旁的杯子像啤酒杯、床墊像展示底座。

### 3D 模型

- 臉和頭髮細節是重點 → 偏好分開生成。
- 尾巴（赫蘿）：蓬鬆、圓潤、有毛的層次；暖棕色、尾端奶白；不要扁平羽毛感、不要火龍果質感。
- 任何角度（包括從底部往上看）都不能有破洞、縫隙、錯位。
- 最終是一個封閉、相連的整體（在 Blender 套用修改器後）。
