# 製作流程細節

每一步都寫了「做什麼」和「為什麼」。為什麼的部分大多來自實際踩過的坑，詳見 `lessons.md`。

## 0. 概念圖與挑圖

- 概念圖用圖像模型生成（過去用 OpenAI 相容的圖像 API，模型 gpt-image 系列），以固定模板組合：角色基礎 + 服裝 + 姿勢情境 + 尾巴描述。審美偏好見 `aesthetics.md`。
- 做成挑圖頁讓使用者選；選擇存在頁面資料庫，生成前一定先讀取。
- 使用者在挑圖時寫的備註（例如「尾巴不對」「腳可以露出來」）要帶進後續步驟。

## 1. 基準模型 A

- 原圖 → Tripo Studio「Direct Texture ×4」（一次生成 + 三次免費重試，共 4 個候選，8K 貼圖）。
- 用途：對齊參照、截背面圖、決定尾巴大致方向。**不是**成品。
- 花費：一張圖約 50 點，約 20 分鐘。

## 2. 2D 準備

- **去尾巴正面圖**：用圖像編輯把尾巴拿掉，其他保持一致。
- **背面圖（新 B2）**：
  1. 截模型 A 的背面圖（身形、姿勢、配件正確，但頭髮差）。
  2. 圖像模型從正面圖畫一張背面圖（頭髮好看，但身形不一定對）。
  3. 把兩張一起當參考，請圖像模型重畫一張乾淨的背面圖：身形照 1、頭髮照 2。
  4. gpt-image 比 nano-banana 穩（nano-banana 會改變構圖）。
  - 比較過的其他方法：B1（在背面截圖上修頭髮，會保留髮飾）、B3（直接從正面畫背面）。新 B2 最好，B3 次之。舊 B2（遮罩剪貼頭髮）最差，不要用。
- **尾巴圖**：
  - 形狀：細長的彎月形、圓潤蓬鬆。**避免攤開的大扇形**（Tripo 會壓成扁平的羽毛／葉子狀）。
  - 顏色：照概念圖（赫蘿是暖棕色、尾端奶白）。
  - 根部不能有膚色接頭。
  - 好的做法：拿一條已經成功的尾巴圖當範本，依每張概念圖的彎曲方向改形狀。

## 3. 身體生成

### 站姿 → 上下半身分開 + 疊層

- 分開生成的理由：每個部位分到的細節多，臉和頭髮明顯清楚很多。
- 上半身：頭到腰（含手、手上的道具），**保留完整的衣服下襬**，正面 + 背面多視角生成。
- 下半身：
  - 裙子／洋裝：重新生成成「腿 + 貼身短褲」，像裙子裡的打底褲。
  - 褲裝：褲子本身。
- 兩半都先對齊。對齊方式：先對完整的模型 A，再在腰部重疊區域彼此精對齊，必要時微調大小。
- 疊層接合規則：
  - 上半身的腿要**一路切到衣服下襬裡面**，下襬以下看得到的腿 100% 來自下半身模型（不然大腿上會有接縫線）。
  - 衣服下襬完整保留，包括內側。
  - 下半身上緣塞進衣服裡，從低角度往上看也不能看到背景。
  - 外套配褲子：外套下襬在外，褲頭塞在裡面。
  - 下半身自己多長出來的複本（手套、頭髮、包包、外套、裙子）要刪掉，不然會從上半身的衣服裡戳出來。
  - 垂下來的東西（頭髮、手套繩、吊帶、吊飾）一律保留，**不可以用「靠近就刪」「顏色像就刪」這種捷徑**。
  - 裙子裡面可加一層暗色內襯，讓從下面看只看到暗色的內側。
  - 上下兩個模型的膚色若不同，把下半身的膚色調成跟上半身一致。

### 坐姿／蹲姿／躺姿 → 綜合（新 B2）

- 沒辦法從腰部切開的姿勢，用去尾巴正面 + 新 B2 背面一起生成整個身體。
- 坐在大道具上（蘋果、酒桶、月亮、秤、枕頭、雲、棉被……）的圖，道具可能要另外處理（尚未定案）。

## 4. 尾巴接合

- 尾巴模型另外生成（多視角或單圖皆可，重點是尾巴圖的形狀）。
- 找背面：**不能假設某個固定座標軸是背面**。用骨盆左右對稱找中線，頭髮垂下的那一側是背面。
- 根部：腰後正中間、屁股上方；如果衣服下襬遮不住就往上移。
- 接口：先切掉尾巴根部的凸塊／蓋子，再往身體裡埋，直到根部約 97% 以上被身體、頭髮或尾巴自己的毛遮住。**絕對不能露出接合的凸起**。
- 方向／大小／彎度：對照概念圖的尾巴輪廓（軟性目標）。硬性條件：往下垂、在骨盆後面、不穿過腿。使用者接受位置有點偏，但不接受接得不好。

## 5. 一體成形（封閉網格）

- 疊層只是幾個獨立的殼疊在一起，**不算完成**。最後要合成單一、封閉、流形（manifold）的實心網格。
- 做法：先把每個部件各自做成封閉實心（高解析度體素／SDF 重建），再做布林聯集（上半身 + 下半身 + 尾巴 + 垂掛物），然後重新展 UV、把原本的貼圖轉印上去（≥4K）。
- 不要只重建接縫那一圈：Tripo 的殼本來就沒封口，只重建一圈會變成蕾絲狀的鏤空。
- 驗證：只有 1 個整體、沒有邊界邊、沒有非流形邊、法線一致、體積為正；各角度跟前一版並排比較，確認臉和頭髮細節沒掉。
- 輸出 GLB（看）+ STL（列印）。

## 6. 呈現與保存

- 網頁用縮小版：面數減少、貼圖縮到 2K、壓縮後約 2 MB 一個，否則頁面放不下。
- 原檔保存：Tripo 帳號裡有；定案的放 R2；B2 只放小檔（對照清單、程式備份）和最終成品。
- 每完成一步就把「對照清單」（哪張圖 ↔ 哪個 Tripo 任務 ↔ 哪個候選 ↔ 狀態）上傳到雲端，機器被回收也能從 Tripo 找回來。
