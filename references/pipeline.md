# 製作流程細節（2026-10-18 版）

每一步寫了「做什麼」和「為什麼」。為什麼大多來自實際踩過的坑，見 `lessons.md`。

## 0. 概念圖與挑圖

- 概念圖用圖像模型生成（OpenAI 相容的圖像 API，gpt-image 系列），模板：角色基礎 + 服裝 + 姿勢情境 + 尾巴描述。審美偏好見 `aesthetics.md`。
- 挑圖頁：縮圖網格、放大、「做成模型」、備註；選擇存在頁面資料庫。已做過模型的圖標「已做模型」並預設隱藏。
- 挑圖時的備註（「尾巴不對」「腳可以露出來」）要帶進後續步驟。

## 1. 基準模型 A

- 原圖 → Tripo Studio Direct Texture ×4（4 個候選、8K 貼圖），一張約 50 點、約 20 分鐘。
- 用途：截背面圖、尾巴大致方向的參考。
- **不能當對齊標準**：Tripo 從單張圖推立體，身體轉向每次都不同；上下半身分開生成時兩半各猜各的。

## 2. 2D 準備

- **去尾巴正面圖**：圖像編輯拿掉尾巴，其他不變。
- **背面圖（新 B2）**：模型 A 的背面截圖（身形對）+ 圖像模型從正面畫的背面圖（頭髮好），兩張一起當參考重畫背面。gpt-image 比 nano-banana 穩。B3（直接畫背面）次之；舊 B2（遮罩剪貼）不要用。
- **尾巴圖**：細長彎月形、圓潤蓬鬆；避免攤開的大扇形（會變扁平羽毛／葉子）；顏色照概念圖（赫蘿：暖棕、尾端奶白）；根部不能有膚色接頭。好方法：拿成功的尾巴圖當範本改彎度。

## 3. 分開生成

- **站姿**：
  - 上半身：頭到腰（含手、道具），**保留完整的裙子／毛衣／外套下襬**；正面 + 背面多視角生成。分開生成臉和頭髮細節明顯更好。
  - 下半身：裙裝 → 腿 + 貼身短褲；褲裝 → 褲子本身；正面 + 背面多視角。
- **坐姿／蹲姿／躺姿**：沒辦法從腰切開 → 整個身體一起生成（去尾巴正面 + 新 B2 背面）。坐大道具的圖道具跟身體一起生成。躺姿（趴在床墊上）基準模型常被壓扁，可能不適合。
- **尾巴**：另外生成。

## 4. 各零件補成封閉實體

- Tripo 零件常見問題：背對背的零體積重複面（造成非流形邊）、少量開口、分離的小碎片。
- 做法：去掉零體積重複面、補開口（新面顏色取鄰近貼圖）、合併重複頂點。保留 >99.9% 原始面。
- **不准**體素／SDF／泊松重建、減面、縮貼圖、重烘貼圖。補不起來就停下回報（例如衣服只有單層沒有厚度），不要偷偷重建。
- 下半身模型常常自己多長一份上身／裙子／包包／頭髮的複本 → 只留下半身該有的部分。

## 5. 對齊方向

- 用兩半真正重疊的地方對齊：上半身腿端到下襬之間的大腿（上半身裙下沒有獨立的臀部可用）。只做剛體旋轉，轉軸在髖部中心。
- 量化：髖線、大腿中心位置、下襬處的扭轉角。單腿前後傾斜不同是姿勢差異，剛體旋轉修不掉。
- 做幾個角度候選給使用者看；**最終角度交給使用者在 Blender 自己調**。

## 6. 實體布林接合（絕不刪面）

- 刪面就是開洞 → 之前所有破洞的根源。每一步都必須保持封閉。
- 上半身的大腿：用**平滑的切除體**減掉——下半身大腿的封閉副本沿法線外擴約 1.5–3 mm，從下襬高度往下；必要時再加一個貼著下襬內緣的平滑放樣。切除體**不能用薄片疊**（會在裙內留下一圈圈條紋）。
- 切面顏色取最近的裙子底面頂點的貼圖座標，看起來像裙子裡布。
- 上半身殘留在裙底和切面之間的薄皮要清掉（之前造成大腿上的「破皮」）。
- 合併：(上半身 − 切除體) ∪ 下半身 ∪ 尾巴，用保留貼圖座標的精確布林（manifold3d）。
- 尾巴：根部要真的插進身體（只算身體）。位置可以偏，但不能浮、不能露接頭；做法可選：調角度避開重疊、重畫尾巴形狀讓根部延長、或平滑拉長根部（移動頂點、保留貼圖座標）。
- 驗收見 `process.md`。

## 7. 交付

- **主要交付：`.blend`，零件不合併**：
  - 物件：Upper、Lower（原點在髖部中心，起始角度與參考角度記在自訂屬性）、Tail、Cutter_Thighs（隱藏、綁在 Lower 上）。
  - Upper 上掛**未套用**的 Exact 布林修改器：減切除體 → 聯集 Lower → 聯集 Tail。使用者轉 Lower 即時看到結果，滿意再依序套用。
  - 原始貼圖打包進檔案；附中文說明文字。
  - 交付前在 Blender 重新開檔驗證：物件、修改器、面數、貼圖尺寸、評估後是否封閉。
- **彩色列印**：3MF（帶貼圖）為主、OBJ+MTL+原始貼圖為輔；STL 只能單色。重新讀回確認顏色一致。
- 成品上傳 R2 `final/`。

## 8. 給使用者看的頁面

- 原始品質：GLB 切成 ≤11 MB 的區塊（副檔名用平台接受的類型），前端下載後組回並用 SHA-256 檢查，再交給 three.js 載入。畫面上顯示面數和貼圖尺寸證明沒縮。
- 一頁只放一張圖；只放最新成品與必要的比較版本；切換版本時鏡頭不動。
- 提供使用者常用的視角按鈕（正面、背面、左右、頂、底、裙底仰視、尾巴根部、大腿進裙襬側面）。
