# 派工單範本

複製下面整段，把 `〈 〉` 換成實際內容再派給 agent。agent 看不到對話，所以不要寫「照剛剛說的」——該說的都寫進來。

```text
# 任務：〈圖名〉—〈一個問題，例如「尾巴根部沒有插進身體」〉

## 範圍
- 只處理：〈圖名〉的〈零件／部位〉。
- 目標：〈做完後應該是什麼樣子，用一兩句白話〉。
- 使用者原本的描述（轉述）：〈…〉。必須照這個方法做；若做不到，停下回報，不要換成別的做法。

## 不要做
- 不處理其他圖、其他問題；不更新頁面、不上傳成品（另有人負責）。
- 不減面、不縮貼圖、不重烘貼圖、不重建網格（體素／SDF／泊松／remesh）。
- 零件封閉之後不刪面；形狀只能用精確布林改。
- 不讀、不複製、不上傳任何登入檔或金鑰。
- 〈其他，例如「不要改上半身」〉

## 輸入
- 工作資料夾：〈路徑〉
- 檔案：〈零件模型、概念圖、背面圖、上一版 .blend 的路徑〉
- manifest：〈路徑〉（任務 ID、版本、狀態）
- 參考：figure-create skill 的 references/pipeline.md 第〈N〉步、references/verification.md

## 可用工具
- 〈Blender（無頭模式）、精確布林函式庫、圖像 API、圖轉 3D 服務工具…〉

## 做法
1. 〈步驟〉
2. 〈步驟〉
（主對話已經跟使用者確認過這個做法。）

## 驗收（全部要附截圖或數字）
- [ ] 只顯示接合區、各零件不同顏色、單面顯示、洋紅背景：底部／內側／左右低角度／近拍
- [ ] 使用者截圖的那個角度：〈描述〉
- [ ] 整隻模型重新檢查一次（不只修的地方）
- [ ] 數字：單一整體、0 開口邊、0 非流形邊、接合處無自我穿插、體積為正
- [ ] 面數與來源比對；貼圖與原檔逐位元相同
- [ ] 〈本任務特有的檢查〉

## 輸出
- 檔案寫到：〈路徑，檔名含版本，例如 i1_v7.blend〉
- 更新 manifest：版本、檔案路徑、狀態「待驗」
- 截圖存到：〈路徑〉

## 時間
- 上限〈45〉分鐘。超過 30 分鐘時先回報一次進度（附截圖）。
- 到上限就停下，回報目前狀態，不要自己延長。

## 回報格式（≤〈200〉字）
1. 實際用了什麼做法（若跟上面不同，說明原因）
2. 看起來怎樣、還有哪裡壞（附截圖路徑）
3. 驗收清單逐項結果
4. 輸出檔路徑、manifest 是否已更新
```
