# 踩過的坑（已淘汰的做法）

每條：做了什麼 → 結果 → 現在怎麼做。標 **［已淘汰］** 的做法不要再用；這裡只是讓你知道為什麼。

## 2D 與生成

- **配件跟身體一起生成** → 配件貼圖很糟（尾巴像火龍果質感）。→ 配件另外畫、另外生成（`pipeline.md` 2c、3）。
- **攤開的大扇形尾巴圖** → 被做成扁平寬毛束，像羽毛或葉子。→ 細長彎月形、圓潤蓬鬆。
- **配件圖顏色太淡、根部有膚色接頭** → 顏色照概念圖，提示詞明確要求根部沒有接頭。
- **只給正面圖** → 背面頭髮糊成一團。→ 一定要有背面圖。
- **［已淘汰］遮罩剪貼背面圖**（把畫好的頭髮剪下貼到模型背面截圖上；舊稱「舊 B2」）→ 邊緣對不齊，還蓋掉蝴蝶結等配件。→ 雙參考重畫背面。
- **誤解使用者的方法**：使用者說「兩張參考圖重畫」，第一次卻做成遮罩剪貼。→ 收到新方法先白話覆述確認。

## 修補與接合

- **［已淘汰］切割縫合**（兩半各切一刀再縫起來）→ 縫線皺、有小洞。
- **［已淘汰］只重建接縫那一圈**（在沒封口的殼上做帶狀 remesh）→ 變成蕾絲狀鏤空。
- **［已淘汰］疊層**（兩半疊在一起、靠刪面藏接縫，不做布林）→ 腰部透空黑帶、破洞、斷掉的手套繩、飄浮的頭髮碎片；最後仍是分開的網格，不能列印。
- **［已淘汰］體素／SDF 重建成封閉版** → 細節變軟、頭髮變粗、貼圖重烘。→ 只補洞＋精確布林。
- **刪面「修破洞」**（一次刪了約 5,800 個面）→ 正面毛衣破了一個洞。→ 封閉後絕不刪面。
- **依高度或顏色整片刪面**（例如「靠近頭髮就刪」「顏色像就刪」）→ 誤刪手套、垂掛物，破洞一堆。也是「實作偷換做法」的典型。
- **切除體太低** → 上半身自己的大腿露在下襬外，大腿上出現接縫線。→ 切除體頂端在下襬裡面。
- **用薄片疊成的切除體**（每片 0.5 mm）→ 切面變階梯，裙內一圈圈條紋。→ 平滑的一整塊。
- **切面只填一個顏色** → 裙內灰帶。→ 取最近的下襬底面貼圖座標。
- **殘留薄皮被誤判成裙底** → 大腿上一片像撕破的皮。→ 擴大切除體，從正面近拍檢查。
- **配件只碰到頭髮** → 其實浮在身體外。→ 根部插進身體，隱藏頭髮驗收。

## 拆件圖與生成

- **各零件圖各自重畫** → 蘋果的大小、位置、葉子都變了，下半身比裙子空間大，接起來只能切平大腿（出現平台）。→ 全部從同一張正面圖修改，疊回原圖檢查。
- **把原圖的腿像素貼回零件圖** → 模型大腿中段、膝蓋出現一圈圈像娃娃關節的接縫，位置正好是貼回的邊界；事後磨平也去不掉（貼圖上也有線）。→ 零件整張用圖像模型的輸出。
- **分開生成的上半身眼睛** → 多次出現 1.7–2.3 mm 深的眼角細縫，印出來是黑線；整體生成的版本沒有。→ 生成後用白模（不上色）近拍眼睛檢查並回報。平滑補片填平眼窩的做法使用者不滿意（跳步退回補片前的版本），不要再當成標準修法；新的修法要先試做給使用者比較。
- **切除體用直立的柱狀範圍**（例如裙底平板的輪廓往上擠出）→ 裙子往腰部收窄，上方的裙褶被切出洞。→ 切除範圍貼著要切的面（高度場），不要用平頂柱體。
- **調色只做在材質節點** → 匯出 GLB／3MF 時不保留。→ 另存一張調過色的同解析度貼圖。

## 方向

- **假設固定座標軸就是背面** → 身體轉了 34°、43°、61° 時，尾巴被接到屁股側邊或大腿前面。
- **照抄基準模型的方向** → 基準模型自己就可能長歪；上下半身各自生成，轉向也不一致。→ 用重疊的大腿粗略對齊，最終角度交給使用者。
- **花時間做多個角度候選** → 使用者自己在 Blender 調比較快。→ 只做粗略對齊。

## 呈現與溝通

- **給使用者看減面版**（約 12% 面數、2K 貼圖）→ 使用者無法判斷品質，也不是驗收的檔案。→ 原始品質、切塊載入。
- **每個實驗一個分頁** → 使用者不知道看哪個。→ 每張只放最新成品，舊版收起。
- **叫使用者挑他已經決定的事** → 已表態就直接做。
- **還沒挑圖就送出生成** → 先挑後做；送錯馬上取消並告知。
- **交付合併好的模型** → 使用者要的是零件分開、可在 Blender 調角度的 .blend。→ 交付前確認格式與是否合併。
- **把「figure」誤會成圖表** → 這裡指模型手辦。不確定的詞直接問使用者。

## 派工與環境

- **一次派太多事**（修＋套用 6–15 張＋對照圖＋頁面＋發布＋備份）→ 一個任務跑 7–9 小時，檢查被省略。→ 一張圖、一個問題、一個 agent。
- **自己修、自己驗、自己說過關** → 多次回報「乾淨」，使用者隔天就找到洞。→ 修、驗、發布分開。
- **實作跟描述不同**：描述給使用者聽的做法是對的，程式卻用了捷徑。→ 要求回報實際做法並附證明截圖；查錯派新的 agent 讀程式。
- **多條線同時改同一批檔案、程式複製分叉** → 修正沒套到另一批。→ 同一批檔案同時只一個 agent。
- **一次從有下載上限的儲存下載 1.1 GB** → 當天額度用光，所有頁面卡住。→ 先估量，大檔放沒有下載上限的儲存。
- **實驗版本全留在本機**（累積到 28 GB）→ 硬碟塞滿。→ 整批封存，核對後刪本機。
- **長時間計算被中斷**（容器重開、閒置回收）→ 每步更新 manifest，接手時從 manifest 重新派工。
