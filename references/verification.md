# 驗收清單

修的 agent 要逐項附截圖或數字，但**不能自己宣布過關**。每次修完，**另派一個沒參與修改的驗收 agent** 照本清單逐項檢查；主對話再**自己逐張看**驗收截圖、和原圖並排比，兩邊都過才給使用者。每次局部修正後，整隻模型都要重新跑一次。

驗收 agent 的回報格式：每一項寫「過／不過＋截圖路徑＋一句理由」；不確定就寫不過。

## A. 接合處目視檢查

- [ ] **隔離**：只留接合區附近（腰、下襬、配件根部），其他部位全部隱藏。
- [ ] **分色**：上半身、下半身、配件各用不同的純色（另做一組帶原始貼圖的）。
- [ ] **單面顯示（背面剔除）＋洋紅背景**：看到洋紅 = 有洞；看到某片面的背面 = 法線或封閉有問題。雙面顯示會讓洞後面露出另一片暗色內面，看不出洞。
- [ ] 角度：正下方仰視、從內側、左右低角度、近距離特寫。
- [ ] **使用者截圖的那個角度**（有就一定要截）。
- [ ] 下襬以下的腿 100% 來自下半身（分色圖裡看不到上半身的顏色）。
- [ ] 裙內沒有一圈圈條紋、沒有灰帶；大腿上沒有殘留薄皮（從正面近拍大腿）。
- [ ] **配件接觸**：隱藏頭髮後再看，根部是否插進身體；只算身體，頭髮和配件自己的毛不算。
- [ ] 整隻模型：正、背、左、右、頂、底六個方向（帶貼圖）。

## A2. 和原圖比對（每次都要）

- [ ] **原圖並排**：同一個鏡頭（原圖的視角）把成品和原圖並排；臉、手、配件、道具逐一比。
- [ ] **比例**：在原圖上量（像素）再在成品同視角量：臉寬、手寬、手指寬、手腕寬、道具寬、腿長等，列表寫差多少；差超過約 5% 要說明。
- [ ] **手**：數手指（大拇指＋四指，至少從 3 個角度數，數字寫在圖上）；握法和原圖一樣；沒有黏進道具、沒有多出指頭；手的大小和手腕粗細跟原圖比。
- [ ] **臉和眼睛**：不上色的白模近拍正面、斜側、從下方 45°（擺在架上的視角）；眼睛不能是挖空的洞或有深細縫。
- [ ] **配件（尾巴）**：根部插在背部正中線、隱藏頭髮看沒有凸起；長度、角度、質感跟原圖比；不穿過裙子。
- [ ] **道具**：形狀、蒂頭／把手等細節跟原圖一樣（數量也要對，例如葉子幾片）。
- [ ] **裙子和腿**：分色圖看沒有下半身從裙子穿出來、裙子沒被切破；大腿上沒有平台或切面。
- [ ] **坐姿**：坐在道具上沒有浮空、沒有陷太深；從側面看位置合理。

截圖一律**隱藏頭髮等擋視線的東西**，只拍要比的部位。

## B. 數字檢查

- [ ] 單一整體（1 個相連元件）。
- [ ] 0 開口邊（boundary edge）、0 非流形邊（non-manifold edge）。
- [ ] 布林後沒有自我穿插（特別是接合處）。
- [ ] 體積為正（法線朝外）。
- [ ] 三角面數：每個封閉零件（布林前）≥ 來源的 99.9%（扣掉 `pipeline.md` 第 4 步記錄的整塊移除）；合併結果的面數合理。
- [ ] 貼圖：與原始檔逐位元相同（比 hash），尺寸未縮。
- [ ] 交付的 .blend：重新開檔後物件、修改器、自訂屬性都在；修改器評估後的結果同樣通過以上數字檢查。

## C. 不可靠的指標（以前出過事）

| 指標 | 為什麼不可靠 | 改用 |
|---|---|---|
| 「配件接口被遮住 ≥97%」 | 把頭髮、配件自己的毛都算進去；只算身體時只有 48–63%，配件其實浮著 | 隱藏頭髮，只算身體 |
| 整隻模型的破洞自動偵測 | 洞被裙子、腿、頭髮擋住；雙面顯示時洞後面是暗色內面，不是背景 | 隔離接合區＋單面顯示＋洋紅背景 |
| agent 自己判定「可疑像素不是洞」 | 自己修、自己驗，傾向說過關 | 截圖交給主對話或另一個驗收 agent 判斷 |
| 只檢查修過的地方 | 修背面時把正面弄破過 | 每次修完整隻重檢 |
| 在減面／縮貼圖的預覽上驗收 | 看不出真正的品質，也不是交付的檔案 | 一律用原始品質檔案 |
| 「五根手指分開」這類文字描述 | agent 沒有真的數；圖片模型常少畫被擋住的手指 | 驗收 agent 和主對話各自數，數字寫在截圖上 |
| 只看接合處、不比原圖 | 手比例、握法、眼睛凹洞、尾巴角度都會漏 | A2 原圖並排＋量比例 |
| 主對話只看 agent 挑好的幾張圖 | 問題常在沒附的角度 | 用檢討頁本身的預設視角截圖驗收 |
